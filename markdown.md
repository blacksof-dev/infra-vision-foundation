## 📌 Admin Dashboard – Usage Guidelines

Please read the following instructions carefully before using the dashboard.

---

### 🔐 1. Login & Session Issues

- If you face any issues while uploading data, please **log out and log in again** before retrying.
- Ensure your session is active before submitting large files.

---

### 🖼️ 2. Image Upload Guidelines

- Maximum allowed image size: **3 MB**
- For better performance and optimized storage, always upload images in **WebP format**
- Ensure images are properly compressed before uploading

---

### 📄 3. PDF Upload Guidelines

- Maximum allowed PDF file size: **10 MB**
- Verify the file before uploading to avoid duplicate submissions

---

### 📝 4. Form Submission Rules

- Carefully review all entered information before submitting
- Ensure all required fields are properly filled
- Read all instructions displayed in the form section before final submission

---

### ⚠️ 5. Data Upload Issues

- If you encounter any upload errors:
  - First, refresh the page
  - If the issue persists, log out and log in again
  - Always check whether the data has already been uploaded before attempting to resubmit

---

### ✅ Best Practices

- Avoid multiple rapid submissions
- Maintain consistent file naming conventions
- Double-check previously uploaded records before creating new entries

### ⚠️ Blog Update Visibility Notice

If you make any updates to a blog, the changes may not appear immediately on the website.

- It can take approximately **1–2 minutes** for the updated content to reflect.
- The delay occurs because the page is statically generated and revalidated by Next.js.
- The updated version is generated internally after the **first user visits the page** following the update.
- Once regenerated, all subsequent visitors will see the latest version without delay.

This behavior is part of the caching and revalidation process and does not indicate an error.
